一、修改总结
===============================================================================

本轮修改专注于解决攻击效果不佳的问题，未进行大规模重构：

✓ 1. CV 作为第三目标参与进化
   - obj_cv = log1p(total_cv)
   - objectives 从 (2, P) 扩展为 (3, P)
   - NSGA-II 现在优化：隐蔽性、破坏性、约束违反度

✓ 2. 关闭 DNC-aware mask
   - 默认值: use_dnc_aware_mask = False
   - 原因: 日志显示敏感维度比例仅 0.04%，不可靠
   - 保留代码，可通过参数重新启用

✓ 3. 构造约束安全的 guidance (g_safe)
   - sign_safe_weight: 削弱与良性均值符号相反的维度
   - subspace_repair_strength: 移除子空间主成分投影
   - 应用于: 精英种子、directional push、objective evaluation

✓ 4. Sign 约束归一化
   - layer_loss = violation_norm / reference_norm
   - 避免参数量大的层主导整体约束
   - sign_layer_quantile 可配置（默认 0.9）

✓ 5. 每 10 代打印 CV 统计
   - population min CV
   - population mean CV
   - selected individual CV
   - feasible ratio

七、故障排查
===============================================================================

如果服务器运行出错:

1. UnboundLocalError: 'g_safe' referenced before assignment
   → 检查 g_safe 构造是否在 benign_refs 定义之后
   → 应该在 "良性参考系统预计算完成" 日志之后

2. NSGA-II 报错 "objectives shape mismatch"
   → 检查 objectives 是否为 (3, P)
   → 检查所有 compute_objectives 调用是否传入 g_safe

3. CV 一直不下降
   → 检查 obj_cv 是否正确添加到 objectives
   → 检查 g_safe 是否真的被使用 (看日志)
   → 尝试增加 sign_safe_weight

4. GPU OOM
   → 与原版本相比，新增 g_safe 仅增加一个 D 维向量
   → 显存增量应该可忽略
   → 如果 OOM，可能是其他原因
